# Context Compaction in Agent Harness Engineering

## Companion code and exercise answers

**Daniel Raaid · First edition (2026)**

This is the companion repository for *Context Compaction in Agent Harness Engineering: Theory, Mechanisms and Production Engineering*.

The materials are arranged in **12 chapter directories**: [chapters/01](chapters/01) through [chapters/12](chapters/12).

Each chapter contains:

- `examples.py`: the Python code listings transcribed from the corresponding chapter. Some chapters include multiple independent demonstrations; inspect imports and variable scopes before running a combined file.
- `solutions.md`: the chapter's exercise questions, explanatory answer guide, and any non-Python demonstration snippets that were identified.
- Additional files in some chapters provide other original listings.

## How to use

Read the relevant book chapter, open `chapters/NN/solutions.md` for the answer guide and `chapters/NN/examples.py` for demonstrations. Execute independent Python examples in isolated environments. The book includes synthetic or deliberately unsafe counterexamples; do not deploy them as operational security controls.

The answer guides provide reasoned model responses to conceptual and design exercises rather than claiming every open-ended question has one unique implementation. Execution validation of the combined scripts is not yet established and should be performed before presenting them as tested packages.
